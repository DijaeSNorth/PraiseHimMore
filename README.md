# Praise Him More Client Preview

Static GitHub Pages test environment for the Praise Him More radio website.

## Preview behavior

- YouTube videos and livestream links use the official Praise Him More channel.
- The artist submission form prepares an email to praisehimmore@yahoo.com.
- GitHub Pages cannot run the production radio proxy, so the radio control opens the official Way Network player.
- The production Sites build retains the same-page radio proxy.

## Publish

Upload all files in this folder to the root of the `main` branch. In GitHub, open **Settings > Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
